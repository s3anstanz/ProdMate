Design · draft · 2 Nov 2026

prodmate, mapped as a double diamond

An open source agent skill that reads an app built with AI, works out which production-readiness items apply, checks what's done, fixes what an agent can, runs free audits for what it can't, and gives you a plain to-do list for the rest.

Problem statement

AI-built apps get to "it runs" without anyone asking "is it ready to launch?" The tools that cover the whole list only read and report. The tools that run real audits only cover security.

Discover go wide

What's the real problem, and where would a checker go wrong?

What we found

  • Bloom test run: 12 of 40 items applied. Its real gaps (notarization, release tags, updates) aren't on the list.
  • The list would break Bloom's promise by recommending analytics in a "never touches the network" app.
  • Prior art exists: list-wide skills that only read and report; scanners that only cover security.
  • One skill format (agentskills.io) runs in Claude Code, Codex, Cursor and more, but helper-agent support varies.

Missed opportunities

  • Checklists per app type: macOS, mobile, CLI, API, library, extension, LLM app
  • Compliance overlays: health, payments, kids, EU
  • Go-to-market items: store listing, changelog, support channel, license
  • Generated runbooks for rollback and restore
  • MCP setup so the agent can configure tools for you

Define narrow

What makes prodmate worth building?

Differentiators

  • Knows the app type, not just web
  • Respects the app's promises, and explains every skip in one line
  • Checks for real with free audit tools
  • Fixes with permission, in the repo's own style
  • "Can't verify" is a status, never a silent pass
  • Plain words: usable without knowing GitHub

Anti-goals

  • Breaking an app's stated promise
  • Accounts, spend, DNS, deploys or pushes without approval
  • Claiming a check that didn't run
  • A 40-item wall burying the 3 that matter

Develop go wide

What shape could the solution take?

Packaging

  • Single skill folder as the core (chosen)
  • Claude Code plugin wrapper for /prodmate (later)
  • Manifests per agent like obra/superpowers (if adoption warrants)

Workflow

Detect→ Triage→ Assess→ Report→ Act
  • Rejected: one big pass (shallow, overruns context)
  • Rejected: fix everything on its own (breaks the anti-goals)

Report

  • Tiers: launch blockers → before you grow → polish
  • Status: done · partial · missing · can't verify
  • Who acts: agent fixes · agent checks · you do

Deliver narrow

What ships first, and how do we know it works?

v1

  • Web app and macOS app checklists, plus an LLM-app overlay
  • Audits: Lighthouse, osv-scanner, gitleaks, HTTP Observatory, checkdmarc, codesign/spctl
  • Fixes one approved change at a time; MCP setups suggested, not automatic
  • Installs with npx skills add or a Claude Code marketplace
  • Bloom example report

Evals, written first

  • Bloom: skips SEO and analytics for the right reasons; finds the notarization, tagging and update gaps
  • Next.js app with planted gaps: finds them all
  • LLM app: flags injection, fallback and token limits
  • Run in Claude Code and Codex
